# Посмотри в окно

Локальная проектная работа №3: CSS-оформление приложения с видео из разных городов.

## Запуск

Откройте `index.html` в современном браузере. Для загрузки видео нужен интернет: исходный скрипт обращается к API Яндекс Практикума.


Макет рассчитан на ширину окна от 1200 пикселей. Поиск фильтрует видео по городу и времени суток. Карточки переключают основное видео, кнопка «Показать ещё» загружает следующую страницу.

## Реализация

Использованы Flexbox, локальные шрифты Fira Sans Condensed и Oswald, псевдоэлементы чекбоксов, состояния наведения, нажатия и клавиатурного фокуса. Видео и изображения масштабируются через `object-fit`. Длинный текст карточек ограничен многоточием.
